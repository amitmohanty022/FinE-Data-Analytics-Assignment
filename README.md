# FinE Data Analytics Assignment

Item-format classification assignment: cleaning an Excel dataset, filling in missing values, and training scikit-learn models (Random Forest) to predict the missing item formats.

**🔗 Run it live:** every notebook below opens directly in Google Colab, no setup needed.
